# php_tp8 增长/垂直模块迁移进度

> 目标：将 php_my 中 10 个增长/垂直模块迁移至 php_tp8，使 RN 端对应屏幕在升级后端可用。
> 风格：轻量模型 + Db 直查（与第 1~11 批一致），规避 TP5 getter 魔法差异。

## 已完成（代码 + 路由 + 验证）

| 模块 | 端点 | 验证情况 |
|------|------|----------|
| Points（积分明细） | `points/log/index` | 早前已完成（PointsLog 控制器 + user/PointsLog 模型） |
| **Live（直播）** | `live/room/lists` | 端到端 ✓ 返回分页结构 |
| **Shop（自提点）** | `shop/lists`、`shop/detail` | 端到端 ✓ 真实数据验证 logo/距离等字段格式化 |
| **user/Comment（订单评价）** | `user.comment/{order,lists,delete,append}` | 代码 + 语法 + 链路 ✓（登录拦截正确；提交流程建议 RN 联调确认写库） |
