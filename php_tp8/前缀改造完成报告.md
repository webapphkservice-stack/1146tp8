# 数据库前缀改造完成报告

> 目标：将 `php_tp8` 项目数据表前缀由 `yoshop_` 统一改为 `mybaixin_`。
> 原则：**仅改表前缀**，数据库名 `yoshop_tp8` 保持不变；代码中的函数名/常量/注释中的 `yoshop_` 不属于表前缀，不动。

## 已完成项

| # | 改造点 | 结果 |
|---|--------|------|
| 1 | 库内 112 张表 `RENAME` 为 `mybaixin_` 前缀（`SET FOREIGN_KEY_CHECKS=0` 规避外键约束） | 残留 `yoshop_` 表 **0** |
| 2 | `config/database.php` 的 `prefix` 改为 `'mybaixin_'` | 已生效 |
| 3 | `database/schema.sql`（112 张 `CREATE TABLE`）表名前缀同步 | `yoshop_` 残留 0，`mybaixin_` 112 |
| 4 | `database/delta/*.sql` 增量脚本表名前缀同步 | `ALTER TABLE yoshop_*` → `mybaixin_*` |
| 5 | `seed_*` / `cleanup_*` 测试 SQL 表名前缀同步 | 与运行库一致，避免插入失败 |
| 6 | 注释中的库名 `yoshop_tp8` 还原保留 | 仅库名，按方案不动 |

## 验证结果

- 库内表前缀分布：`mybaixin_ => 112`，`yoshop_` 残留 **0**。
- 框架实测：通过 `prefix` 配置成功查询 `mybaixin_user`（记录数 = 10），前缀改造生效。
- 配置读取：`prefix = mybaixin_`。
- 运行服务：`php think run` 在 `127.0.0.1:8080` 正常，已加载新前缀配置。

## 保持不变（非表前缀，不动）

- 数据库名 `yoshop_tp8`。
- 代码中的 `yoshop_hash` 函数名、`salt` 常量、注释描述性文本（如 `yoshop_user_grade` 注释）。
- 经查 app 代码中**无硬编码表名**（`Db::name()` 与模型 `$name` 均不带前缀，由 `prefix` 自动拼接），故无需改代码。
